# Kev 2048 实验与回放

用 Kev 学玩 2048。本仓库是**可克隆的实验快照**，不是训练服务器。正式训练和完整数据保留在云端；其他设备可以复用训练代码、查看已完成实验和离线回放。

## 回放（不用装模型）

双击 `replay/2048-replay.html`，用浏览器打开。四组对局来自真实的逐步记录；共用进度条对齐步数，不代表两边每一步的盘面相同。一边终局或达到测试上限后，它的棋盘会停在最后一帧，不再显示为仍在走。

## 重跑训练和评测

见 [TRAINING.md](TRAINING.md)。先跑规则与数据校验，再按文档准备固定版本的 Kev 模型，运行小规模训练和评测。正式配方及训练/验证盘面在 `data/stock_scale/`。**下载权重是单独的步骤**；此仓库不内置上游模型、训练环境或云端检查点。新的运行结果请放在本地 `runs/`，不要直接覆盖历史档案。

Windows 笔记本可以按 [PowerShell 测速步骤](TRAINING.md#benchmark-the-windows-laptop-powershell)对照同一训练配置的 CPU 和 CUDA 用时；启动、编码、训练和重载分开记录。

## 实验档案

`experiments/` 只收已经完成的记录。失败结果也保留。区分固定盘面上与搜索老师的一致率，以及从新开局实际打到多大的方块。它们衡量的是不同的事。搜索用于生成或标注训练数据；纯 Kev 评测时，不用搜索代打。

## 同步与备份

- Git 跟踪代码、配置、依赖版本、样例数据，以及核验完的实验和回放。
- 完整训练数据、模型权重、运行缓存、密钥和临时日志不进 Git。重要权重和全量日志需要独立的私有备份。
- 更新档案时新增记录或版本，不覆盖旧结果；不要把尚未结束的测试记作已完成。
