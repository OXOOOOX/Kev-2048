# 训练实验日志模板

为新实验复制本模板，填入真实路径、适用阶段、评测条件和交付责任。控制台事件的字段、示例和验收方法以 [训练进度协议](../../workbench/TRAINING-WATCH.md) 为准。

## 目录和日志

```text
runs/<run>/
  progress.jsonl          # 控制台实时发现、训练批次盘面和候选概率
  resolved-config.json    # 实际生效配置和实验规则
  environment.json        # 代码、设备、精度和依赖版本
  data/manifest.json      # 训练与开发数据、划分、老师版本及文件身份
  train.jsonl             # 更新步数、样本曝光、损失、速度和显存
  epochs.jsonl            # 逐轮、分组和对照指标
  predictions/            # 逐盘动作、概率和标签的行引用
  checkpoints/manifest.json
  decisions.jsonl         # 续训、停止、扩量、评测条件与判定
  REPORT.md
```

详细日志可按实验分支、数据档和种子放入子目录。控制台日志始终放在运行目录顶层，实验日志记录运行 ID 和对应检查点。最终报告附上实际产物和校验值，失败或跳过的实验也记录原因。

## 正式运行前的短试

- [ ] 用本次实际入口和独立短试目录验证事件发布，检查覆盖本次实际执行的阶段及终态。
- [ ] 打开实际控制台及 `/channels`，记录任务出现、进度更新和终态。训练任务另点开实际批次，核对轮次、更新步数、盘面、老师动作和训练前向候选概率。
- [ ] 用小样本检查失败或主动中止的状态呈现，将命令、检查结果和短试路径保存到实验记录。
- [ ] 锁定数据和生效配置，确认开发种子与训练种子隔离、最终 500 个测试种子用量为 0、精度符合约定。
