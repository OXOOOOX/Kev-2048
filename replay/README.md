# 2048 交互回放

双击 **`2048-replay.html`**，在现代浏览器（如 Edge 或 Chrome）里打开。没有安装步骤，不加载模型，不读取外部网站。页面内部已经包含 4 个实验开局的两个原生模型策略。GitHub 的文件预览可能不会运行脚本；请克隆后从本地打开，或下载文件后打开。

- 默认停在同一开局的第 53 步。左侧原版 V2 仍可继续，右侧八方向投票版已经自然结束。
- 可以换种子、拖动时间轴、逐步或倍速播放，也能直跳到首次动作分岔。键盘方向键逐步，空格播放或暂停。
- 描边是本步实际落下的新方块。过了任一侧的记录末尾，该侧保留最后的盘面与分数，不会显示新走法或新方块。
- 终局和步数上限分开标记；例如种子 96626003 的 V2 到 240 步时仍能移动，记录在上限截断。

## 重新生成与校验

在仓库根目录：

```text
python experiments/verify_traces.py verify
python replay/build.py
```

两个命令只需要 Python 3.9+。构建读取 [D4 日志](../experiments/traces/d4.jsonl)与本目录模板，生成与发行文件一致的独立 HTML。不需要 Python 时，可以直接使用生成好的 HTML。

可选逻辑测试（Node.js，无包依赖）：进入 `replay` 目录后运行 `node smoke.cjs`。
