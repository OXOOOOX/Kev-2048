# Kev 2048 本地工作台

本地绿色工作台有三个入口。**训练控制台**按日志列出训练、测评、推理采集和测速。**回看**载入历史记录和星标对局。**即时游玩**用你选中的模型或搜索老师开启本地对局。

在[回看目录](http://127.0.0.1:8765/#review)里，进入目录或重新加载页面时会从 `runs/` 读取已完成的整局测评，默认最近完成的在最上面。停留在目录时，点「刷新目录」可查看新对局。复用的对照保留在原测评下，已星标的即时游玩也会出现。其他文件夹可导入一次，看到「已保存在此浏览器」后，下次用同一浏览器打开同一地址即可回放。

新测试统一放在 `runs/`，每次一个目录。见 [测试结果保存规则](RESULTS.md)。

## 不安装任何东西：即时回看

1. 从克隆的仓库中双击 `index.html`，在 Edge 或 Chrome 打开。
2. 点「回看」，在 Edge 或 Chrome 点「选择文件夹」，找到项目的 `runs/`（自己的记录）或 `experiments/traces/`（历史档案）。列表显示模型、种子、步数、分数、最大方块和时间，点一局即可打开。点「显示更多」可继续找旧记录，已有勾选会保留。也可以直接选择或拖入逐步日志，以及同目录的 `result.json`、可选 `run.json`。可用 `samples/sample-events.jsonl` 试播记录中的四步。
3. 导入一个文件可看单局，同时选多份可按种子比较。界面会优先选择开局一致的两局；如果盘面从开局就不同，会明确提示。不足以还原棋盘的 `benchmark.json` 只能做监控摘要，不能回放。

文件内容只在当前浏览器读取，离线回看不连服务、不上传、不加载模型。文件夹功能只列出你自己选中的范围，不扫描其他目录；浏览器不支持文件夹选择时，仍可直接多选文件。

本机存档和文件夹对局默认按时间从新到旧排列，也可按分数、最大方块或步数排序。各局的最大方块进度使用同一条 0–2048 刻度，在 512、1024、2048 处划分。达到 2048 后条形填满，列表仍显示实际最大方块。「仅看达到 2048」会保留最大方块为 2048 或更大的棋局。文件夹的排序和筛选会先读取所选范围内的对局统计，再分页显示。

目录进度条也会标出每局首次合出 512、1024、2048 的步数。点目录里的步数标记，直接从合成前四步开始回放，到合成时停住。回放时间轴上的标记可以直接跳到该步，或随后选择播放合成过程。

列表优先读摘要和清单，无摘要的记录会限量读取日志预览。缺少对局时间时显示可用的文件时间。打开对局时才验证完整轨迹及伴随文件。支持原生 `play` 的多局摘要（含 `games` 数组），也支持整局开发评测的单局 `result.json`。导入时核对种子、末步步数、分数、最大方块和结束条件。单局摘要还会校验轨迹的 SHA-256；可一并选择 `identity.json` 核对模型和种子。若伴随文件冲突或无法唯一配对，工作台会给出提示并保留之前的回放。多次运行都有同名文件时请选文件夹，普通文件选择器不能提供目录归属。

评测回放显示「官方基线」或候选模型名，可以按种子切换并选两个模型对照。模型标题使用摘要、运行清单或目录中的名称；设备和头指纹按日志报告展示。只选旧日志仍可回放，不能确定结束原因时显示「结束原因未知」。一次最多打开 8 次运行，含伴随文件总计 48 MiB；单日志最多 16 MiB，单个伴随 JSON 最多 1 MiB。打开后，文件夹对局列表会保留，可以继续点开其他对局。

## 训练控制台

打开控制台无需加载模型或 PyTorch。用 Python 3.12 或 3.13，从仓库根目录运行：

```powershell
python workbench/live.py
```

打开[绿色训练控制台](http://127.0.0.1:8765/)。控制台默认每两秒在 `runs/` 下发现新的运行和阶段，也支持按日期分组的运行目录。它识别 `progress.jsonl`、`status.json`、测速和整局测评结果，以及 `watch_train.py` 写入的 `<运行名>.progress.jsonl`。新任务可以沿用已有日志格式，或在进度行声明 `kind` 为 `training`、`evaluation`、`inference` 或 `benchmark`。目录名和轮次可自行选择。其他位置的文件也可用 `--watch` 接入。

```powershell
python workbench/live.py --watch "本轮训练:training:runs/local-a.progress.jsonl" --watch "测速结果:benchmark:runs/bench-smoke/benchmark.json" --watch "候选筛选:evaluation:runs/筛选目录/progress.jsonl" --watch "本轮推理:inference:runs/live/当前对局.jsonl"
```

支持训练进度、静态测速结果、候选筛选和推理步序。不存在的文件显示「等数据」。活动日志停止更新会标记过期，服务断线时保留最后一次收到的数据并显示断线。卡片只显示来源已经报告的阶段、计数、耗时或棋盘。绝对路径也可用，含空格或 Windows 盘符时保留引号。

总览优先显示活动任务，可以按类型筛选。点击任一条目即可查看该来源报告的进度、指标和最近事件。整局测评还可按种子查看多个模型的盘面与决策。数据采集展示已采集局数和日志中的当前目标。

在训练详情的「训练盘面」里可以切换候选配置和训练轮次，再点柱子选择已记录的优化步。每一步表示用一整批盘面更新一次参数。该批记录的盘面每行八张，播放时逐张比较老师走法和更新前候选的四向概率，播完这批自动进入下一条已记录的优化步。可调倍速、按训练吞吐播放、暂停或跟到最新批次。只有轮次指标的旧日志会显示已记录的指标。

选中盘面后可以收藏当前网址。第四轮的 4 个轮次均可查看第 1 至 32 步。原日志保存了 20 个批次的盘面，其余 108 个批次按原采样顺序还原。候选首选和概率由历史权重复算，页面同时标明复算的损失和按日志区间估计的速度。后续训练直接读取每步写入的候选概率。缺少候选输出的样本标为「未记录」。[打开第四轮第 1 轮第 2 步](http://127.0.0.1:8765/?run=watch-training-f481b18e99ebda3a&epoch=1&step=2#train)

### 查看正在运行的整局评测

整局开发测评的配置与日志可自动接入。若要为某个测评指定显示名称，可在启动服务时提供目录。

```powershell
python workbench/live.py --watch "整局开发评测:gameplay:runs/gameplay-dev-head2000-20261123"
```

在「同种子模型对照」中，每根细条对应一个种子。点击细条或用左右键切换，上方显示完整种子号。模型按本轮实际参赛名单并排显示，窄屏可横向滑动种子条和模型对照区。

已完成的测评从开局显示。点「播放」后，各模型按同一步序回放，较早结束的模型停在自己的终局。可暂停、调速、前后走一步，或拖动时间轴跳转，查看该步的盘面、得分、决策和四向概率。「落子前盘面」可对照决策时的棋盘。正在进行的测评默认跟随当前批次，点播放可以回看已记录的走法，「返回实况」可跟回正在运行的对局。

工作台通过 Server-Sent Events 接收变化，服务端最多每 250 毫秒检查一次本地日志。顶部显示当前批次和总批次、评测进程报告的平均落子速度，以及本批已记录落子且尚未结束的种子、模型和对局数量。连续步有滑动、合并和新方块动效，概率条按实际概率平滑过渡。重连时直接显示最新记录；系统设置为减少动态效果时，数据仍实时刷新。

### 如何接入真实训练进度

通过 `kev2048 train`、`kev2048 experiment` 或 `kev2048 improve` 新开的训练会在每次优化器更新后发布记录，适用于原生 Stock / Smoke、决策头和 LoRA。包内使用 `python -m`、`--out` 和共用决策头训练函数的实验也会自动接入。控制台显示本轮步数、总步数和截至该步的平均训练损失，每步最多预览 64 张实际盘面。历史 LoRA 日志也可在能核对采样顺序和训练集时展示盘面。原生训练需要观察拟合前的缓存进度时可用 [TRAINING-WATCH.md](TRAINING-WATCH.md) 的启动方式。

## 即时游玩

从同一本地服务切到「即时游玩」，勾选一个或多个可用模型，也可选已经通过校准的搜索老师。种子为空时会生成新种子。选中的策略各自从同一个种子开局，实时显示棋盘、分数、最新方向和决策数值。神经模型显示方向概率，搜索老师显示各合法方向的搜索评分。

模型卡片列出训练简述，以及最近一次实际整局评测的平均终局分、局数和批次。展开「各轮均分」可查看历史批次和复用记录。若有多批可合并的评测，还会显示按开局种子去重的累计均分。搜索老师单独标明校准批次。新训练发布可用权重或整局评测完成后，打开的即时游玩页会自动更新清单。

对局的开局和每步决策会暂存在本机服务内存。推理可以暂停、继续或提前停止，时间轴可以逐步或连续回看当前对局，多个模型同步跳转到所选步数。对局结束后，点星标会把本次整组走法存入 `runs/instant-play/`，并自动列在「回看」的本机存档里。开下一局或重启本机服务会丢弃未星标的对局。

模型按需加载。官方基线需有本地权重，候选来自已完成的决策头训练，搜索老师使用已有的校准记录。默认使用 CPU；`--device cuda` 可以显式指定 CUDA。用 `--monitor-only` 运行时可以使用控制台和回看。旧版单模型页仍可用 `--enable-live-console` 从 [独立控制台](http://127.0.0.1:8765/console) 打开。
